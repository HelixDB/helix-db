This tutorial takes a new workspace from sign-in to an explored graph and a first
answer. You need a Helix account and a source to read, such as a Stripe account.
Owners and admins of a workspace can do every step. Members can follow along
read-only; exploring a load and asking about it also need **Query read** on its
database's Helix project.

<Steps>
  <Step title="Sign in">
    Open [foundry.helix-db.com](https://foundry.helix-db.com) and continue with
    Google, GitHub or Microsoft, using the account you use for Helix Cloud.

    <Frame>
      <img src="https://assets.helix-db.com/docs/foundry/start-here/sign-in.png" alt="The Helix Foundry sign-in page with Google, GitHub and Microsoft buttons" />
    </Frame>
  </Step>

  <Step title="Choose a workspace">
    Foundry opens your workspace when you have one, or the workspace picker when you
    have several or none. Select **Create workspace** to start a new one; it starts on
    Foundry Free.

    <Frame>
      <img src="https://assets.helix-db.com/docs/foundry/start-here/create-workspace.png" alt="The Create a workspace dialog over the workspace picker" />
    </Frame>
  </Step>

  <Step title="Connect and sync a source">
    In **Data**, select **Add data**, choose the source, and follow its numbered steps
    to create a read-only credential. Select **Test connection** to see what the
    credential can read, then **Connect and sync**. The first sync starts at once.

    <Frame>
      <img src="https://assets.helix-db.com/docs/foundry/data/stripe-tested.png" alt="The Stripe connection form after a successful test, listing the objects the key can read" />
    </Frame>

    See [Connect data](/foundry/data/connect-data) for every source and what it needs.
  </Step>

  <Step title="Upload documents">
    Optional. In **Data**, select **Upload documents** and choose Markdown or text
    files, such as contracts; ontologies don't read other formats yet. They go into the
    **General** document set, in the Data explorer's **Documents** folder.

    <Frame>
      <img src="https://assets.helix-db.com/docs/foundry/data/documents-uploaded.png" alt="The Data explorer with contract.md uploaded into General" />
    </Frame>

    See [Documents](/foundry/data/documents) for sets and what they're for.
  </Step>

  <Step title="Create an ontology">
    In **Ontologies**, select **New ontology**. The page walks you through it one step
    at a time: name it, choose the Helix database it loads into (one you have, or a new
    one on Helix's shared cluster), choose the connectors whose synced tables it reads
    and, optionally, the document sets it reads, such as **General**, and say what it
    should serve. Then select **Create and generate**: Foundry creates the ontology and
    its agent drafts a first version. The page follows the generation until it stores
    the version.

    <Frame>
      <img src="https://assets.helix-db.com/docs/foundry/ontology/new-ontology-review.png" alt="The New ontology page at its Review and create step, with the name, database, data, documents and goal chosen, and Create and generate" />
    </Frame>

    See [Create an ontology](/foundry/ontologies/create-an-ontology) for each step.
  </Step>

  <Step title="Review it and make it current">
    On the generation's page, select **Review version**. Read its types, links,
    mappings and rules, then select **Make current**. Earlier versions stay, so you can
    roll back at any time.

    <Frame>
      <img src="https://assets.helix-db.com/docs/foundry/ontology/version.png" alt="An agent-drafted version that reads General, with its Graph, Types, Links, Mappings, Sources, Rules, Questions, TOML and Edit tabs" />
    </Frame>
  </Step>

  <Step title="Load it">
    On the ontology's overview, select **Load data**. The dialog says which tables and
    document sets the load reads and what it may spend; select **Load**. When it
    finishes, it becomes the current load.

    <Frame>
      <img src="https://assets.helix-db.com/docs/foundry/ontology/load-dialog.png" alt="The Load version 3 into contracts dialog with the tables, the documents from General, spending and limits" />
    </Frame>
  </Step>

  <Step title="Explore it">
    Select **Open Explorer**. The graph opens on a connected sample of the load. Search
    with <kbd>/</kbd>, double-click a node to expand it, or switch to **Records** to read
    each type as a table.

    <Frame>
      <img src="https://assets.helix-db.com/docs/foundry/explore/explorer-node.png" alt="The Explorer with a customer selected and its properties and relationships in the inspector" />
    </Frame>
  </Step>

  <Step title="Ask a question">
    Select **Ask** on the rail, write a question or pick a suggestion, and select
    the arrow. The answer cites the records, rows and quotes it came from.

    <Frame>
      <img src="https://assets.helix-db.com/docs/foundry/ask/thread.png" alt="An Ask thread with its steps and an answer citing its sources" />
    </Frame>
  </Step>
</Steps>
