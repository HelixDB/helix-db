Each workspace has one Foundry plan, billed monthly and separately from Helix Cloud.
Owners and admins change it in **Settings** → **Plan & billing**; members see which plan
the workspace holds.

| | Free | Pro | Max |
| --- | --- | --- | --- |
| Price | $0 | $100 a month | $500 a month |
| Every connector: apps, PostgreSQL, MySQL, Amazon S3 and API sources | ✓ | ✓ | ✓ |
| Ontology generation, versions, loads and Ask | ✓ | ✓ | ✓ |
| [Scheduled syncs](/foundry/data/connect-data#syncs-on-a-schedule) | Daily | Hourly, reading only what changed | Every 15 minutes, reading only what changed |
| [Automatic refreshes](/foundry/ontologies/load-data#automatic-refreshes) | Daily at most | Hourly at most | Every 15 minutes at most |
| Your own [Anthropic key](/foundry/workspace/ai-models) | | ✓ | ✓ |

Max includes everything in Pro, and will add more. The monthly
[spending caps](/foundry/workspace/usage) on loads and questions are the same on every
plan.

## Upgrade

<Steps>
  <Step title="Choose a tier">
    Select **Upgrade**, choose **Pro** or **Max**, and add a promotion code if you have
    one.

    <Frame>
      <img src="https://assets.helix-db.com/docs/foundry/workspace/upgrade.png" alt="The Upgrade Foundry dialog with Pro selected and a promotion code field" />
    </Frame>
  </Step>

  <Step title="Pay">
    Select **Continue to payment**. Foundry opens Stripe Checkout, or charges the card on
    file when the workspace has one.
  </Step>

  <Step title="Come back">
    Stripe returns you to **Plan & billing**, which checks the payment until the new plan
    shows. Connections sync on the new plan's schedule from then on.
  </Step>
</Steps>

If an upgrade's answer is lost, for example when the network drops, the page checks the
plan before it offers checkout again, so you aren't charged twice.

## Switch between Pro and Max

On a paid workspace, select **Switch to Max** or **Switch to Pro** on the other tier's
card and confirm.

<Frame>
  <img src="https://assets.helix-db.com/docs/foundry/workspace/billing-pro.png" alt="Plan & billing for a Pro workspace with Manage billing, Cancel Pro and Switch to Max" />
</Frame>

## Cancel or resume

Select **Cancel Pro** (or **Cancel Max**) and confirm. The plan stays on until the end
of the period, then the workspace moves to Free: its connections sync once a day, and
if it runs on its own model key, its AI work pauses until an owner chooses **Default**
or the workspace is on Pro again (see [AI models](/foundry/workspace/ai-models#if-the-workspace-leaves-pro)).
Until then, **Resume Pro** (or **Resume Max**) undoes the cancellation.

## Manage payment and invoices

Select **Manage billing** to open the Stripe billing portal for the workspace: payment
methods, invoices and billing details. When an invoice isn't paid, the page says so and
offers **Update payment method**; cancelling and switching wait until it's paid.
