Each workspace has one Foundry plan, billed monthly and separately from Helix Cloud.
Owners and admins change it in **Settings** → **Plan & billing**; members see which plan
the workspace holds. Your ontologies' Helix databases run on the workspace's
[Helix Cloud plan](#the-helix-cloud-plan-for-databases) instead.

| | Free | Pro | Max |
| --- | --- | --- | --- |
| Price | $0 | $100 a month | $500 a month |
| Every connector: apps, PostgreSQL, MySQL, Amazon S3 and API sources | ✓ | ✓ | ✓ |
| Ontology generation, versions and loads, [Founder](/foundry/ask/founder), [dashboards](/foundry/automate/dashboards) and [workflows](/foundry/automate/workflows) | ✓ | ✓ | ✓ |
| [Scheduled syncs](/foundry/data/connect-data#syncs-on-a-schedule) | Daily | Hourly, reading only what changed | Every 15 minutes, reading only what changed |
| [Automatic refreshes](/foundry/ontologies/load-data#automatic-refreshes) | Daily at most | Hourly at most | Every 15 minutes at most |
| Your own [Anthropic key](/foundry/workspace/ai-models) | | ✓ | ✓ |

Max includes everything in Pro, and will add more. PostHog syncs at most once a day on
every plan (see [PostHog](/foundry/data/connectors#posthog)). The monthly
[spending caps](/foundry/workspace/usage) are the same on every plan.

## Upgrade

<Steps>
  <Step title="Choose a tier">
    Select **Upgrade**, or **Choose Pro** or **Choose Max** on a plan's card. Pick the
    tier, and add a promotion code if you have one.

    <Frame>
      <img src="https://assets.helix-db.com/docs/foundry/workspace/upgrade.png" alt="The Upgrade Foundry dialog with Pro selected and a promotion code field" />
    </Frame>
  </Step>

  <Step title="Pay">
    Select **Upgrade to Pro** or **Upgrade to Max**. Foundry opens Stripe Checkout, or
    charges the card on file when the workspace has one.
  </Step>

  <Step title="Come back">
    Stripe returns you to **Plan & billing**, which checks the payment for up to a minute.
    If the new plan hasn't shown by then, select **Check again**: a payment can take a few
    minutes. Connections sync on the new plan's schedule from then on.
  </Step>
</Steps>

If an upgrade's answer is lost, for example when the network drops, the page checks the
plan before it offers checkout again, so you aren't charged twice.

## Switch between Pro and Max

On a paid workspace, select **Switch to Max** or **Switch to Pro** on the other tier's
card and confirm. The switch starts at once, at the new tier's price. Promotion codes
apply only when upgrading from Free.

  <img src="https://assets.helix-db.com/docs/foundry/workspace/billing-pro.png" alt="Plan & billing for a Pro workspace with Manage billing, Cancel Pro and Switch to Max" />

## Cancel or resume

Select **Cancel Pro** (or **Cancel Max**) and confirm. The plan stays on until the end
of the period, then the workspace moves to Free: its connections sync once a day, and
if it runs on its own model key, its AI work pauses until an owner chooses **Default**
or the workspace is on Pro again (see [AI models](/foundry/workspace/ai-models#if-the-workspace-leaves-pro)).
Until then, **Resume Pro** (or **Resume Max**) undoes the cancellation.

## Manage payment and invoices

Select **Manage billing** to open the Stripe billing portal for the workspace: payment
methods, invoices and billing details. When an invoice isn't paid, the page says so and
offers **Update payment method**; cancelling and switching wait until it's paid.

## The Helix Cloud plan for databases

Ontologies load into Helix databases, and a database on Helix's shared cluster needs a
Helix Cloud plan on the workspace. It's separate from the Foundry plan, and billed in
the [Helix dashboard](https://helix-db.com/login).

- A workspace created in Foundry comes with Helix Cloud's **Idea** plan, free for 12
  months, without a card.
- A workspace that has never had a Helix Cloud plan, such as one Foundry made before
  this offer, gets the same the first time Foundry creates a database for it.
- Each workspace gets it once.

When the free months end, choose a Helix Cloud plan in the Helix dashboard. Without an
active plan, Foundry can't create databases, and the Explorer, Records and entity pages
may say queries are paused.

Foundry links to Helix billing when a new database can't be created (**Open Helix
billing**): the workspace's Helix plan has ended, or the workspace signed up through the
Helix website, which has its own offer. The
[Explorer](/foundry/explore/explorer#when-theres-nothing-to-read), Records and entity
pages link there too when queries are paused: **Choose a plan** when the workspace has no
Helix plan, else **Open Helix billing**.
