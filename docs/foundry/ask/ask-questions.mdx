Ask answers questions about an ontology's load in plain language. Foundry's agent reads
the load from the ontology's database step by step, and its answer cites each record,
table row, quote and rule it used, so you can open every one.

## Start a thread

Select **Ask** in the sidebar or on the rail. It opens the ontology you last opened; the **Ontology**
picker at the top of the threads panel opens another. A new thread asks what you want
to know about the ontology, with the composer in the middle of the page and, when
Foundry has read the load's version, the version's questions as suggestions.

<Frame>
  <img src="https://assets.helix-db.com/docs/foundry/ask/new-thread.png" alt="A new Ask thread: What do you want to know about Customer contracts?, the composer, two suggested questions, and the Load picker in the top bar" />
</Frame>

Write the question, or select a suggestion, then select the arrow or press
<kbd>⌘</kbd> <kbd>Enter</kbd> (<kbd>Ctrl</kbd> <kbd>Enter</kbd> on Windows and Linux).
A question is at most 4,000 characters.

Ask reads one load: the current one, unless you choose another in the **Load** picker
in the top bar. A load can be asked about once it is **Ready** or **Partial**.

## Read an answer

A thread is one column: each question, then its steps as they run, then the answer,
with the composer pinned at the bottom.

- **Steps** say what the agent read, such as the entities it found or the query it
  ran, written as a path through the ontology's types and links. Each step's JSON is
  behind a disclosure. A step that failed says why, and the agent carries on.
- **The answer** is plain text with numbered citations, then **Sources**: each record,
  fact, derived fact, table row, document quote, rule break or step it cites. Select one
  to open it: an entity's page, the row's table, the quote in its document, or the step.
- Below the answer, what the question cost and the tokens it used.

While a question runs, **Cancel** stops it.

<Frame>
  <img src="https://assets.helix-db.com/docs/foundry/ask/thread.png" alt="A thread asking Who signed the services agreement?, with its last steps, an answer citing eight sources, the follow-up composer, and two threads under Today" />
</Frame>

Follow up in the same thread: the composer at the bottom asks with the thread's earlier
answers. A thread takes one question at a time, so a follow-up waits until the answer
before it is ready.

## Threads

The threads panel, beside the sidebar's rail, lists the ontology's threads by their
first question, grouped **Today**, **Previous 7 days** and **Older**. A thread being
answered says so. **New thread** starts another. The foot of the panel shows what the
workspace has spent on questions this month, out of its monthly budget; select it for
the limits. Hide the panel with the toggle at the top of the rail.

On a phone, Ask shows the threads first; choose one, or **New thread**, to open it.

## Ask about a record

On an entity's page, select **Ask about this** to ask about that record in a drawer.
The question is about the entity and the load the page reads; **Open in Ask** opens its
thread.

## When Ask can't answer

| What the thread says | What it means |
| --- | --- |
| **This ontology can't answer that** | What the load holds doesn't say. Ask says why, and what the ontology lacks. **Draft a new version with this** opens [Generate](/foundry/ontologies/generate-and-version) with a goal written from the question. |
| **Stopped at this question's limit** | The question used its budget, steps or time before it could answer. Ask something narrower. |
| **It couldn't answer** | It stopped with an error, which it names. |
| **An attempt failed. Helix will try again** | A passing failure; the question runs again by itself. |
| **Waiting for this month's questions budget** | The month's budget can't hold what a question may spend. It runs once it can, or you can cancel it. |

## Limits and spending

Ask uses AI models: it sends your question, and what each step reads from the load, to
Anthropic models. Questions are billed against their own monthly budget, apart from
loads'.

| Limit | Value |
| --- | --- |
| Per question | $0.50, 10 steps and 2 minutes |
| Questions running per workspace | 2; others wait, queued |
| Questions per workspace, per hour | 30 |
| Per workspace, per month | The budget shown at the foot of the threads |
| Question | 4,000 characters |

## Who can ask

Anyone in the workspace who can read the ontology's database: members need **Query
read** on the database's Helix project. Ask only reads the load; it never writes to
the database.
