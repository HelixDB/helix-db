Stop a background local instance and remove its containers. Local only.

## Usage

```bash
helix stop [INSTANCE]
```

## Arguments

| Argument | Description |
| --- | --- |
| `INSTANCE` | Local instance to stop. If omitted in a TTY with multiple instances, the CLI prompts. Defaults to `dev` when present, otherwise the only local instance. |

## Behavior

- `helix stop` is idempotent — if the instance is not running, the CLI exits successfully without error.
- Default in-memory data is wiped when the container is removed.
- For disk-mode instances, `helix stop` removes the Helix and MinIO containers but keeps the persistent local volume. Use [`helix prune`](/cli/command-reference/prune) to delete disk-mode data.
- Remote S3 data is never touched.

## Examples

```bash
# Stop the default 'dev' instance
helix stop dev

# Stop with interactive picker
helix stop

# Safe to call in scripts even if the instance is already stopped
helix stop staging
```
