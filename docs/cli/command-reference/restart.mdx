Restart an existing background local instance in place, using its current image and container settings. Readiness is checked on the existing container's published port, including a temporary `helix start --port` override. Restart never pulls an image or creates a replacement container. If the container has been removed, the command fails. Use [`helix start`](/cli/command-reference/start) to create a container or apply new image or configuration settings.

Default local data is in-memory and is wiped by every restart. Disk-mode instances preserve data in their local SeaweedFS volume.

## Usage

```bash
helix restart [INSTANCE]
```

## Arguments

| Argument | Description |
|----------|-------------|
| `INSTANCE` | Local instance to restart. If omitted in a TTY with multiple instances, the CLI prompts. Defaults to `dev` when present. |

## Examples

```bash
# Restart the default 'dev' instance
helix restart dev

# Restart with interactive picker
helix restart
```
