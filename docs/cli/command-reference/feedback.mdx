Send feedback to the Helix team by opening a pre-filled GitHub issue in your browser. No login is
required.

## Usage

```bash
helix feedback [MESSAGE]
```

## Arguments

| Argument | Description |
| --- | --- |
| `MESSAGE` | Feedback text used as the issue body. If omitted, the body is `Helix CLI feedback`. |

## Behavior

- Opens a new issue on `github.com/helixdb/helix-db` titled `feedback: Helix CLI`, with your message as the body.
- Nothing is sent until you submit the issue on GitHub, so you can edit it first.
- The CLI does not prompt for a message.

## Examples

```bash
# Open an issue with your message filled in
helix feedback "love the new dynamic query flow"

# Open an issue with the default body
helix feedback
```
