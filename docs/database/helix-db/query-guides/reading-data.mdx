Every traversal starts from a source. Choose the narrowest source that matches the
data you already know.

## Source choices

| Intent | Builder |
| --- | --- |
| One or more node IDs | `n(NodeRef.ids([...]))`; `NodeIDs(...)` in Go |
| Node IDs from a parameter | `n(NodeRef.param("ids"))`; `NodeParam("ids")` in Go |
| Nodes with a label | `nWithLabel` / `n_with_label` |
| Labeled nodes matching a source predicate | `nWithLabelWhere` / `n_with_label_where` |
| Nodes matching a source predicate, any label | `nWhere` / `n_where` |
| One or more edge IDs | `e(EdgeRef.ids([...]))`; `EdgeIDs(...)` in Go |
| Edges with a label | `eWithLabel` / `e_with_label`, or `eWithLabelWhere` / `e_with_label_where` |
| Earlier named entry | `n(NodeRef.var(...))`; `NodeVar(...)` in Go |

An ID list returns nodes in the given order and skips missing IDs. An ID parameter is
one non-negative integer ID or an array of them, typed (`i64`, `{ "array": "i64" }`) or
untyped. Any other value fails the query.

Source predicates are eligible for index push-down. Secondary indexes are defined per
label, so a source must be scoped to a label to read one: `nWithLabelWhere` /
`n_with_label_where`, or a `.where(...)` directly after `nWithLabel`. A source predicate
without a label scans every node. A `.where(...)` later in a traversal filters the
current stream.

## Read active users

<CodeGroup>

```rust Rust
read_batch()
    .var_as(
        "users",
        g()
            .n_with_label("User")
            .where_(Predicate::eq("status", "active"))
            .limit(25)
            .value_map(Some(vec!["$id", "name"])),
    )
    .returning(["users"]);
```

```ts TypeScript
readBatch()
  .varAs(
    "users",
    g()
      .nWithLabel("User")
      .where(Predicate.eq("status", "active"))
      .limit(25)
      .valueMap(["$id", "name"]),
  )
  .returning(["users"]);
```

```go Go
helix.ReadQuery("active_users").
	VarAs(
		"users",
		helix.G().
			NWithLabel("User").
			Where(helix.PredEq("status", "active")).
			Limit(25).
			ValueMap("$id", "name"),
	).
	Returning("users")
```

```python Python
(
    read_batch()
    .var_as(
        "users",
        g()
        .n_with_label("User")
        .where(Predicate.eq("status", "active"))
        .limit(25)
        .value_map(["$id", "name"]),
    )
    .returning(["users"])
)
```

```json JSON
{
  "request_type": "read",
  "query_name": "active_users",
  "query": {
    "read": {
      "entries": [{
        "query": {
          "name": "users",

            "value_map": {
              "input": {
                "limit": {
                  "input": {
                    "where": {
                      "input": {
                        "nodes_where": {
                          "predicate": {
                            "eq": {
                              "left": { "property": "$label" },
                              "right": { "constant": { "string": "User" } }
                            }
                          }
                        }
                      },
                      "predicate": {
                        "eq": {
                          "left": { "property": "status" },
                          "right": { "constant": { "string": "active" } }
                        }
                      }
                    }
                  },
                  "count": { "literal": 25 }
                }
              },

```

```cypher Cypher
MATCH (u:User)
WHERE u.status = 'active'
WITH u LIMIT 25
RETURN id(u) AS id, u.name AS name
```

```sql SQL
SELECT id(u) AS id, u.name AS name
FROM User u
WHERE u.status = 'active'
LIMIT 25
```

</CodeGroup>

## Read by indexed property

Scope the source predicate to the indexed label, so the property read uses its index:

<CodeGroup>

```rust Rust
g().n_with_label_where("User", SourcePredicate::eq("email", "alice@example.com"))
```

```ts TypeScript
g().nWithLabelWhere("User", SourcePredicate.eq("email", "alice@example.com"))
```

```go Go
helix.G().NWithLabelWhere("User", helix.SourceEq("email", "alice@example.com"))
```

```python Python
g().n_with_label_where("User", SourcePredicate.eq("email", "alice@example.com"))
```

```json JSON
{
  "request_type": "read",
  "query_name": "user_by_email",
  "query": {
    "read": {
      "entries": [{
        "query": {
          "name": "user",
          "root": {
            "nodes_where": {
              "predicate": {
                "and": {
                  "predicates": [
                    {
                      "eq": {
                        "left": { "property": "$label" },
                        "right": { "constant": { "string": "User" } }
                      }
                    },
                    {
                      "eq": {
                        "left": { "property": "email" },
                        "right": {
                          "constant": { "string": "alice@example.com" }
                        }
                      }
                    }
                  ]
                }
              }
            }
          }
        }
      }],
      "returns": ["user"]
    }
  }
}
```

```cypher Cypher
MATCH (user:User {email: 'alice@example.com'})
RETURN id(user) AS user
```

```sql SQL
SELECT id(u) AS "user"
FROM User u
WHERE u.email = 'alice@example.com'
```

</CodeGroup>

## Read an earlier result

Use `NodeRef.var("user")` (or the equivalent SDK reference) as the source of a later
entry. Named references are transaction-local; they do not create stored variables or
routes.

## Results without a projection

An entry without a projection, such as `g().nWithLabel("User").limit(25)`, returns one
`{"$id": ...}` per node or edge (plus `$distance` or `$score` after a search) and no
properties. To read properties, end with `valueMap`, `project`, or another
[projection](/database/helix-db/query-guides/projections).
