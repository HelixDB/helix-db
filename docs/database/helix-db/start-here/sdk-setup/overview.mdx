Every HelixDB SDK builds the same operation-tree request and sends it to
`POST /v2/query`, so the query guides apply to all four languages. Pick the SDK for
your application's language:

| SDK | Package | HTTP client | Embedded runtime |
| --- | --- | --- | --- |
| Rust | `helix-db` (imported as `helix_db`) | Async | Yes, behind the `embedded` feature |
| TypeScript | `@helix-db/helix-db` (ESM, Node.js 20+) | Async | Yes |
| Go | `github.com/helixdb/helix-db/sdks/go` | Yes | Not yet |
| Python | `helix-db` (imported as `helixdb`) | Sync and async | Yes, with `helix-db-embedded` |
