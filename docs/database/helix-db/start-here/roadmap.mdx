## In progress

- **Smarter cache warming** (ongoing)
- **Reliability and availability improvements** (ongoing)
- **Support for non-HA clusters**
- **Backups and point-in-time recovery**
- **Expanded query plans for better performance**

## Up next

- **SSO and SAML**
- **RBAC and fine-grained API key permissions**
- **AWS PrivateLink**
- **Audit logs**

## Recently shipped

- **Cypher and SQL query endpoints** (`POST /v2/cypher`, `POST /v2/sql`)
- **`helix doctor` and the `GET /v2/diagnostics` endpoint**
- **Graph Explorer for local instances** (`helix explorer`)
- **Optional durability waits and a configurable WAL upload interval**
- **Index builds that finish under sustained writes without stalling reads**
- **Asynchronous vector and text indexing with strong or eventual search**

See the [release notes](/database/helix-db/start-here/release-notes) for everything
that has shipped.
